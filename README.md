# task-tracker-backend

## Project goal: A task tracker with a Task Service and a Notification Service.

### Planned components: Task Service, Notification Service, Eureka Server and PostgreSQL.
### Learning goals: Java, Spring Boot, REST APIs, SQL, Flyway, Swagger/OpenAPI, service discovery and Git.
### Environment: record your Java 17 and Maven versions. Run java -version and mvn -version (or ./mvnw -version if you already have a Maven wrapper).
